  Email Automation System

A Python-based email automation system that can send personalized emails to multiple recipients using Gmail SMTP.

   Features

- Send emails automatically using Python
- Send emails to multiple contacts
- Read contacts from CSV
- Personalized email templates
- Custom email subject
- PDF attachment support
- Schedule emails for a specific time
- Email sending logs
- Simple Tkinter GUI
- Success and failure tracking

    Technologies Used

- Python
- Pandas
- Tkinter
- SMTP
- Schedule
- CSV
